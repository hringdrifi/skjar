# SKJÁR

**SKJÁR** は、横長のタッチディスプレイと小型 Linux コンピュータを一体にした、40% のメカニカルキーボード / Cyberdeck です。

物理キーは文字入力に必要な最小限にとどめ、数字列・F キー・マクロ・メディア操作・ステータス表示などはタッチディスプレイ側に持たせます。PC につなげば普通の USB キーボードとして動き、本体側では Linux のアプリケーションが動きます。

> [!WARNING]
> **開発中のプロジェクトです。** 回路図・基板はまだ試作も動作確認もしていません。誤りが含まれている可能性が高いので、**このままの設計データで基板を発注したり、部品を買いそろえたりしないでください。** 内容は予告なく大きく変わります。

**状態：** 回路図を作成中（基板の配置・配線は未着手）。決めたことは [docs/design-decisions.md](docs/design-decisions.md)、残っていることは [docs/open-items.md](docs/open-items.md) にあります。

---

## 名前の由来

古ノルド語の `skjár` から取りました。中世アイスランドで、半透明の膜を張った採光用の窓を指した言葉です。現代アイスランド語では「screen / display」を意味します。横長のディスプレイを主役にした本機に合わせた名前です。

---

## 設計思想

SKJÁR では、ディスプレイを「おまけ」として扱いません。物理キーとタッチ UI を合わせて、1つの入力システムにします。

一般的な 60% キーボードに画面を足すのではなく、

**必要最小限の物理キー ＋ 状況に応じて変わるソフトウェアキー**

という構成を基本にします。

---

## コンセプト

- 40% のコンパクトな物理キーボード
- 上部に 8.8″ の横長タッチディスプレイ
- Linux を搭載
- PC からは普通の USB HID キーボードとして見える
- タッチ UI を物理キーの拡張として使う
- Cyberdeck 的な自由度
- ケーブル1本でも全機能が動く（相手が 5 V / 1.5 A 以上を出せる場合）

## 構成

```text
        PC                          充電器 / PC（開発・書き込み）
         │                                   │
  Port A (USB-C)                      Port B (USB-C)
  HID ＋ 給電                          開発・rpiboot ＋ 給電
         │                                   │
         │      ┌──────────────────────┐     │
         ├─VBUS─┤ TPS2121（電源切り替え）├─VBUS┤   B 優先・5 µs で切り替え
         │      └──────────┬───────────┘     │
         │                 │ 5V              │
    ┌────┴─────┐  UART  ┌──┴───────────┐     │
    │  RP2040  ├────────┤     CM0      ├─USB─┘
    │ HID・電源の│        │  Linux・UI   │
    │ 判断・CC   │        └──┬────┬────┬─┘
    └────┬─────┘           │    │    │
         │              DSI   I²C   I²S
   キーマトリクス          │    │    │
     （40%）        8.8″ LCD  RTC  アンプ
                     （タッチ）（CR2032）（スピーカー）
```

| 部分 | 内容 |
|---|---|
| メインコンピュータ | Raspberry Pi Compute Module 0（CM0100008：Cortex-A53 ×4 / 1 GHz、512 MB、eMMC 8 GB、Wi-Fi / BT） |
| キーボード用マイコン | RP2040（PC への HID、電源の判断、CC の判定） |
| ディスプレイ | Waveshare 8.8inch DSI LCD または 8.8-DSI-TOUCH-A（480×1920、10点タッチ、DSI 2レーン） |
| 電源 | USB-C ×2、5 V 専用（PD なし）、上限 15 W。TPS2121 で切り替え |
| RTC | PCF8563T ＋ 32.768 kHz 水晶 ＋ CR2032 |
| 音声 | MAX98357A（I²S アンプ）＋ スピーカー（後付け） |
| OS | Raspberry Pi OS Lite。デスクトップ環境は使わず、専用 UI を直接起動する |

詳しい仕様と理由は [docs/design-decisions.md](docs/design-decisions.md) を見てください。

## タッチ UI でやりたいこと

数字列、F1〜F12、マクロキー、レイヤーの表示と切り替え、メディア操作、音量スライダー、輝度調整、アプリランチャー、PC のステータス表示、時計、CPU / RAM / ネットワークの表示、WPM 表示、アニメーション、動画再生、トラックパッドモード、ジェスチャ入力、アプリごとに変わる UI。

# 電源シート（power.kicad_sch）

回路図を描くための仕様。決めた理由は [design-decisions.md](../design-decisions.md) の「2. 電源」、ネット名は [pin-assignment.md](../pin-assignment.md) を参照。

定数は計算値。**[要決定]** は、描く前に決める項目。

**手本：** 全ピンにネットラベルを付けた版を [power-reference.pdf](power-reference.pdf)（画像は [power-reference.png](power-reference.png)）に書き出してある。`hardware/pcb/power.kicad_sch` には、同じ配置で部品だけを並べてある（配線なし）。

---

## 1. 全体の流れ

```text
Port B (USB-C) ─ VBUS_B ─┐                         ┌─ TPS22965 ─ +5V_LCD ─→ display
                         ├─ TPS2121 ─ +5V ─────────┼─→ cm0（CM0 の 5V）
Port A (USB-C) ─ VBUS_A ─┘  IN1=B / IN2=A          └─ LDO ─ +3V3 ─→ rp2040、peripherals

Port A の D+/D-  ─ USBLC6 ─→ rp2040（USB_A_D+/-）
Port B の D+/D-  ─ USBLC6 ─→ cm0   （USB_B_D+/-）
各ポートの CC1/CC2 ─ Rd 5.1 kΩ ─→ rp2040（CC1_A, CC2_A, CC1_B, CC2_B）
```

---

## 2. USB-C コネクタ（2個：J_A = Port A、J_B = Port B）

シンボル：`Connector:USB_C_Receptacle_USB2.0_16P`
部品：HRO TYPE-C-31-M-12（LCSC **C165948**）
フットプリント：`Connector_USB:USB_C_Receptacle_HRO_TYPE-C-31-M-12`

| ピン | 接続 |
|---|---|
| VBUS（A4/B4/A9/B9） | すべて `VBUS_A`（または `VBUS_B`）へ |
| GND（A1/B1/A12/B12） | すべて GND へ |
| CC1（A5） | 5.1 kΩ（1%）で GND へ。同じ点から `CC1_A`（または `CC1_B`）として rp2040 へ |
| CC2（B5） | 5.1 kΩ（1%）で GND へ。同じ点から `CC2_A`（または `CC2_B`）として rp2040 へ |
| D+（A6 / B6） | 2本をつないで、USBLC6 を通して `USB_A_D+`（または `USB_B_D+`）へ |
| D-（A7 / B7） | 2本をつないで、USBLC6 を通して `USB_A_D-`（または `USB_B_D-`）へ |
| SBU1 / SBU2 | 未接続（ノーコネクトのフラグを付ける） |
| SHIELD | GND へ直結 |

- **Rd は個別の抵抗にする：** RP2040 が起動する前から、相手に給電を始めてもらうため。
- **CC から rp2040 への線：** ADC の入力を保護するために、rp2040 側で 1 kΩ の直列抵抗を入れてもよい（rp2040 シートで扱う）。
- **D+ / D- の2本ずつ：** 表裏どちらで挿しても動くように、A 側と B 側を基板上でつなぐ。

## 3. USB の ESD 対策（2個）

シンボル：`Power_Protection:USBLC6-2SC6`

| ピン | 接続 |
|---|---|
| I/O1 / I/O2（両側） | D+ / D- の線の途中に入れる（コネクタのすぐ近くに置く） |
| VBUS（5） | **`+5V`**（TPS2121 の後ろ。各ポートの VBUS には直接つながない） |
| GND | GND |

- **USBLC6 の中身：** D+ / D- の静電気を VBUS 側か GND 側に逃がすダイオードの組と、VBUS と GND の間の TVS（約 6 V から導通）でできている。
- **5 番ピンを `+5V` につなぐ理由：** 各ポートの VBUS に直接つなぐと、故障した充電器が高い電圧を出し続けたとき、TPS2121 の過電圧保護より先に内蔵の TVS が電流を吸い込み続けて壊れるおそれがある。過電圧保護を通った後の `+5V` につなげば、内蔵の TVS が見るのは 5 V だけになり、データ線の静電気対策の働きは変わらない。

## 4. VBUS の過電圧対策

**TVS ダイオードは付けない。** 代わりに TPS2121 の過電圧保護（OV1 / OV2）を使う（5 章）。

- **抜き差しの瞬間の跳ね上がり：** TPS2121 は入力が落ち着くのを待ってから、ソフトスタートで出力を出す。そのため、跳ね上がりは TPS2121 の入力で止まり、`+5V` には届かない。入力側は 22 V まで耐える。
- **故障した充電器が高い電圧を出し続ける場合：** OV1 / OV2 でその入力を遮断する。TVS は一瞬のサージ向けで、続く過電圧には向かない。

## 5. 電源切り替え：TPS2121（U_MUX）

シンボル：`Skjar:TPS2121RUX`（LCSC C485916）

| ピン | 接続 | 定数 |
|---|---|---|
| IN1（7） | `VBUS_B` | 1 µF のセラミックコンデンサを GND へ |
| IN2（2） | `VBUS_A` | 1 µF のセラミックコンデンサを GND へ |
| PR1（6） | `VBUS_B` を分圧 | 上 100 kΩ / 下 51 kΩ（比 0.338、5 V で 1.69 V） |
| CP2（3） | `VBUS_A` を分圧 | 上 100 kΩ / 下 43 kΩ（比 0.301、5 V で 1.50 V） |
| OV1（5） | `VBUS_B` を分圧 | 上 100 kΩ / 下 22 kΩ（約 5.88 V で遮断） |
| OV2（4） | `VBUS_A` を分圧 | 上 100 kΩ / 下 22 kΩ（約 5.88 V で遮断） |
| OUT（1, 8） | `+5V` | 下の「出力側のコンデンサ」を参照 |
| ST（9） | `PWR_ST`（rp2040 へ） | 10 kΩ で `+3V3` にプルアップ |
| ILM（10） | 抵抗で GND へ | 30 kΩ（約 2.46 A） |
| SS（11） | コンデンサで GND へ | 100 nF（約 780 V/s） |
| GND（12） | GND | |

**切り替えの動作（計算値）**
- **Port B だけ：** CP2 が VREF（1.06 V）未満なので、PR1 だけで判定する。Port B の電圧が約 3.1 V を超えれば IN1（Port B）を使う。
- **Port A だけ：** PR1 が 0 V なので、IN2（Port A）を使う。
- **両方：** PR1 > CP2 の間は Port B を使う。Port B の電圧が「Port A の電圧 × 0.89」を下回ると、5 µs で Port A に切り替わる（Port A が 5.0 V なら、Port B が約 4.45 V を下回ったとき）。

**過電圧保護（OV1 / OV2）**
- 判定電圧の誤差は ±5% なので、実際に遮断するのは約 5.59〜6.17 V。USB の VBUS の上限（5.5 V）より高いので、正常な相手で誤って遮断することはない。
- 分圧抵抗は電源の通り道に入らないので、電圧降下は増えない（分圧に流れる電流は約 41 µA）。
- 遮断した入力は使わず、もう片方のポートが生きていればそちらに切り替わる。

**出力側のコンデンサ（`+5V`）**
- 470〜1000 µF の低 ESR コンデンサ（ポリマー）＋ 10 µF のセラミック × 2。
- USB の規格では VBUS に直接つないでよい容量は 10 µF までだが、TPS2121 より後ろなので、ソフトスタートで突入電流が抑えられる。

## 6. LCD 用の負荷スイッチ：TPS22965（U_LCDSW）

シンボル：`Skjar:TPS22965DSG`（LCSC C122837）

| ピン | 接続 | 定数 |
|---|---|---|
| VIN（1, 2） | `+5V` | 1 µF のセラミックコンデンサを GND へ |
| VBIAS（4） | `+5V` | |
| ON（3） | `LCD_EN`（rp2040 から） | 100 kΩ で GND にプルダウン（初期状態は OFF） |
| CT（6） | コンデンサで GND へ | 1〜2.2 nF（立ち上がりを緩やかにする。値はデータシートの表で決める） |
| VOUT（7, 8） | `+5V_LCD` | 10 µF のセラミックコンデンサを GND へ |
| GND（5, 9） | GND | 9 は裏面の放熱パッド |

## 7. 常時 ON の 3.3V：LDO（U_LDO）

**AP2127N-3.3TRG1（Diodes、LCSC C176954、Extended。手持ちの在庫を使う）**。シンボルは `Regulator_Linear:AP2127N-3.3`、パッケージは SOT-23（1 GND、2 VOUT、3 VIN）。データシート DS36478 Rev. 7。

- **当初は XC6206P332MR-G（C5446、Basic）だった。** ピン配置もフットプリントも同じ。AP2127 は出力電流・ドロップアウト・絶対最大定格・保護機能で上回り、手持ちがあるので替えた。

- **入力：** `+5V`。入力と出力に 1 µF のセラミックコンデンサ（X5R / X7R。データシートの推奨どおり）。EN ピンはなく、常時 ON。
- **最大電流：** 300 mA（ドロップアウト 170 mV）。過電流・短絡・過熱の保護付き。
- **入力電圧：** 動作範囲は 2.5〜6 V、絶対最大は 6.5 V。過電圧保護が遮断する直前（最大 約 6.17 V）は動作範囲をわずかに超えるが、絶対最大の内側に収まる。
- **負荷：** RP2040、QSPI フラッシュ、RTC、プルアップ類で 50 mA 程度の見込み。
- **注意：** CM0 には CM0 自身の 3.3V（`+3V3_CM0`）がある。`+3V3` とはつながない。

## 8. テストパッド

`VBUS_A`、`VBUS_B`、`+5V`、`+5V_LCD`、`+3V3`、`PWR_ST`、GND。

## 9. シート外とつなぐグローバルラベル

| ラベル | 向き |
|---|---|
| `USB_A_D+` / `USB_A_D-` | 出力（→ rp2040） |
| `USB_B_D+` / `USB_B_D-` | 出力（→ cm0） |
| `CC1_A` / `CC2_A` / `CC1_B` / `CC2_B` | 出力（→ rp2040） |
| `PWR_ST` | 出力（→ rp2040） |
| `LCD_EN` | 入力（← rp2040） |

`+5V`、`+5V_LCD`、`+3V3`、GND は、グローバルラベルではなく電源シンボル（グローバルなネット）で扱う。

# RP2040 シート（rp2040.kicad_sch）

回路図を描くための仕様。GPIO の割り当ては [pin-assignment.md](../pin-assignment.md) の「3. RP2040 の GPIO」、決めた理由は [design-decisions.md](../design-decisions.md) を参照。

**[要決定]** は描く前に決める項目、**[要確認]** は描きながらデータシートで確かめる項目。

**手本：** [rp2040-reference.pdf](rp2040-reference.pdf)（画像は [rp2040-reference.png](rp2040-reference.png)）。`hardware/pcb/rp2040.kicad_sch` には同じ配置で部品だけを並べてある。部品番号は 100 番台（U101、R101、C101 など）。

## 2. 電源まわり（`+3V3` から）

| ピン | 接続 | 部品 |
|---|---|---|
| IOVDD（1, 10, 22, 33, 42, 49） | `+3V3` | **各ピンに 100 nF**（ピンの近くに置く） |
| USB_VDD（48） | `+3V3` | 100 nF |
| ADC_AVDD（43） | `+3V3` | 100 nF |
| VREG_VIN（44） | `+3V3` | 1 µF |
| VREG_VOUT（45） | DVDD（23, 50）へ | VREG_VOUT に 1 µF、DVDD の各ピンに 100 nF |
| TESTEN（19） | GND | |
| GND（57、裏面のパッド） | GND | |

- **1.1 V のコア電源：** RP2040 内蔵のレギュレータで作る（VREG_VOUT → DVDD）。外付けのレギュレータは要らない。
- **ADC_AVDD の雑音対策：** CC の判定は電圧の範囲が広いので、RC フィルタは入れずにコンデンサだけにする。

## 3. 水晶（12 MHz）

| ピン | 接続 |
|---|---|
| XIN（20） | 水晶の一端、負荷コンデンサで GND へ |
| XOUT（21） | 直列抵抗を通して水晶のもう一端へ、負荷コンデンサで GND へ |
| 水晶の GND 端子（2, 4） | GND |

- **負荷コンデンサ：** 2 ×（20 pF − 浮遊容量 約 3〜5 pF）≒ **30〜33 pF**（各 1 個）。
- **XOUT の直列抵抗：** Raspberry Pi の設計資料では 1 kΩ を入れている（水晶を過剰に駆動しないため）。ただし資料の推奨水晶は負荷容量 10 pF・ESR 50 Ω で、C9002（20 pF・80 Ω）とは条件が違う。**[要確認]** RP2040 のハードウェア設計資料で、直列抵抗の値を決める。
- **ファームウェア側の対策：** 水晶の起動が遅い場合に備えて、pico-sdk の `PICO_XOSC_STARTUP_DELAY_MULTIPLIER` を大きめ（例：64）にしておく。

## 4. QSPI フラッシュ（W25Q128JVSIQ、SOIC-8 208 mil）

| RP2040 | W25Q128 | 
|---|---|
| QSPI_SS（56） | /CS（1） |
| QSPI_SD1（55） | DO / IO1（2） |
| QSPI_SD2（54） | /WP / IO2（3） |
| QSPI_SD0（53） | DI / IO0（5） |
| QSPI_SCLK（52） | CLK（6） |
| QSPI_SD3（51） | /HOLD / IO3（7） |
| `+3V3` | VCC（8）、100 nF |
| GND | GND（4） |

- **配置：** RP2040 のすぐ近くに置き、配線は短く揃える。

## 5. BOOTSEL と RUN

| 信号 | 接続 |
|---|---|
| QSPI_SS（56） | **BOOTSEL スイッチ**を 1 kΩ を介して GND へ。押しながら Port A を挿すと UF2 の書き込みモードになる |
| RUN（26） | 10 kΩ で `+3V3` にプルアップ。テストパッドを付ける（GND に落とすとリセット） |
| SWCLK（24）/ SWDIO（25） | テストパッドだけ（CM0 にはつながない） |

- **普段のファーム更新：** CM0 から UART のコマンドで「UF2 の書き込みモードで再起動」を送れるので、BOOTSEL スイッチは、初回の書き込みとファームが壊れたときの復旧用。

## 5.1 CM0 の USB ブート要求スイッチ

| 信号 | 接続 |
|---|---|
| `BOOT_SW`（GPIO20） | スイッチ SW102 で GND へ。10 kΩ で `+3V3` にプルアップ |
| `BOOT_EN`（GPIO23） | cm0 シートの Q202（2N7002）のゲートへ。High で CM0 の nRPI_BOOT を Low に引く |

- スイッチは RP2040 だけにつながり、CM0 のピンには直接つながない（CM0 が OFF のときに逆電圧をかけないため）。
- RP2040 は `BOOT_SW` が押されていたら、`BOOT_EN` を High にしてから GLOBAL_EN を解除する（電流宣言が Default でも、CM0 だけ ON にする）。

## 6. USB（Port A）

| RP2040 | 接続 |
|---|---|
| USB_DP（47） | 27 Ω を介して `USB_A_D+`（power シートから） |
| USB_DM（46） | 27 Ω を介して `USB_A_D-`（power シートから） |

- **27 Ω の位置：** RP2040 の近くに置く。
- **PC がつながっているかの判定：** `CC1_A` / `CC2_A` の電圧で判定し、つながっていないときは USB を有効にしない（自分で給電しているデバイスなので、相手がいないときに D+ をプルアップしてはいけないため）。

## 7. GPIO

| GPIO | ピン | 信号 | 接続先 | 備考 |
|---|---|---|---|---|
| 0〜6 | 2〜8 | `ROW0`〜`ROW6` | keymatrix | |
| 7〜12 | 9, 11〜15 | `COL0`〜`COL5` | keymatrix | 内部のプルアップを使う |
| 13〜14 | 16〜17 | 予備 | — | テストパッドを付ける |
| 15 | 18 | `CM0_PWROFF` | cm0 | ゲートのプルアップは cm0 シート側 |
| 16 | 27 | `RP_TXD` | cm0 | UART0 TX。cm0 シートのバッファへ |
| 17 | 28 | `CM0_TXD` | cm0 | UART0 RX。**プルなし** |
| 18 | 29 | `LCD_EN` | power | プルダウンは power シート側 |
| 19 | 30 | `PWR_ST` | power | プルアップは power シート側 |
| 20 | 31 | `BOOT_SW` | このシート内 | USB ブート要求スイッチ（SW102）を読む |
| 21 | 32 | `CM0_RUN_PG` | cm0 | **プルなし** |
| 22 | 34 | `CM0_HALT` | cm0 | **プルなし** |
| 23 | 35 | `BOOT_EN` | cm0 | Q202 のゲートへ（プルダウンは cm0 シート側） |
| 24〜25 | 36〜37 | 予備 | — | テストパッドを付ける |
| 26〜29 | 38〜41 | `CC1_A` / `CC2_A` / `CC1_B` / `CC2_B` | power | 各 1 kΩ の直列抵抗を介して ADC へ |

- **CC の直列抵抗（1 kΩ）：** 過電圧保護でその入力が遮断され、RP2040 の電源が切れているときでも、相手の Rp から ADC のピンに電流が流れ込みすぎないようにするため。
- **配置で入れ替える可能性：** RP2040 の外周のピンの並びを見て、キーマトリクスの配線が交差しないように、ROW と COL の割り当ては基板の配置のときに調整する。

## 8. テストパッド

`+3V3`、GND、RUN、SWCLK、SWDIO、GPIO13・14・24・25（予備）。

回路図を描くための仕様。GPIO の割り当ては [pin-assignment.md](../pin-assignment.md) の「3. RP2040 の GPIO」、決めた理由は [design-decisions.md](../design-decisions.md) を参照。

**[要決定]** は描く前に決める項目、**[要確認]** は描きながらデータシートで確かめる項目。

**手本：** [rp2040-reference.pdf](rp2040-reference.pdf)（画像は [rp2040-reference.png](rp2040-reference.png)）。最初の配置を書き出したもので、その後の変更（キー入力の I²C、キーの RGB、SW102 の廃止など）は入っていない。正は `hardware/pcb/rp2040.kicad_sch`。部品番号は 100 番台（U101、R101、C101 など）。

## 2. 電源まわり（`+3V3` から）

| ピン | 接続 | 部品 |
|---|---|---|
| IOVDD（1, 10, 22, 33, 42, 49） | `+3V3` | **各ピンに 100 nF**（ピンの近くに置く） |
| USB_VDD（48） | `+3V3` | 100 nF |
| ADC_AVDD（43） | `+3V3` | 100 nF |
| VREG_VIN（44） | `+3V3` | 1 µF |
| VREG_VOUT（45） | DVDD（23, 50）へ | VREG_VOUT に 1 µF、DVDD の各ピンに 100 nF |
| TESTEN（19） | GND | |
| GND（57、裏面のパッド） | GND | |

- **1.1 V のコア電源：** RP2040 内蔵のレギュレータで作る（VREG_VOUT → DVDD）。ネット `+1V1` は電源記号（`power:+1V1`）で描く。外付けのレギュレータは要らない。
- **ADC_AVDD の雑音対策：** CC の判定は電圧の範囲が広いので、RC フィルタは入れずにコンデンサだけにする。

## 3. 水晶（12 MHz）

| ピン | 接続 |
|---|---|
| XIN（20） | 水晶の一端、負荷コンデンサで GND へ |
| XOUT（21） | 直列抵抗を通して水晶のもう一端へ、負荷コンデンサで GND へ |
| 水晶の GND 端子（2, 4） | GND |

- **負荷コンデンサ：** **27 pF**（C0G、C107045）を各 1 個。前に作った基板（Segl）で、同じ水晶・27 pF・1 kΩ の組み合わせで動いた実績がある。計算上の値（2 ×（20 pF − 浮遊容量 3〜5 pF）≒ 30〜33 pF）より少し小さいので、周波数はわずかに高めになるが、発振の余裕は増える。
- **XOUT の直列抵抗：** 1 kΩ（Raspberry Pi の設計資料と Segl と同じ）。起動が不安定なら、小さくすると余裕が増える。
- **Raspberry Pi の推奨回路との違い：** 設計資料の回路は ABM8-272-T3（負荷容量 10 pF・ESR 50 Ω）に 15 pF。負荷容量 20 pF の水晶は大きなコンデンサが要るぶん発振の余裕が小さいが、実績を優先した。駄目なら ABM8-272-T3（C20625731）と 15 pF に替える（フットプリントは同じ）。
- **ファームウェア側の対策：** 水晶の起動が遅い場合に備えて、pico-sdk の `PICO_XOSC_STARTUP_DELAY_MULTIPLIER` を大きめ（例：64）にしておく。

## 4. QSPI フラッシュ（W25Q128JVPIQ、WSON-8 6 × 5 mm）

裏面の放熱パッドはどこにもつながない（データシートでは未接続か GND でよい）。

| RP2040 | W25Q128 | 
|---|---|
| QSPI_SS（56） | /CS（1） |
| QSPI_SD1（55） | DO / IO1（2） |
| QSPI_SD2（54） | /WP / IO2（3） |
| QSPI_SD0（53） | DI / IO0（5） |
| QSPI_SCLK（52） | CLK（6） |
| QSPI_SD3（51） | /HOLD / IO3（7） |
| `+3V3` | VCC（8）、100 nF |
| GND | GND（4） |

- **配置：** RP2040 のすぐ近くに置き、配線は短く揃える。

## 5. BOOTSEL と RUN

| 信号 | 接続 |
|---|---|
| QSPI_SS（56） | **BOOTSEL スイッチ**を 1 kΩ を介して GND へ。押しながら Port A を挿すと UF2 の書き込みモードになる |
| RUN（26） | 10 kΩ で `+3V3` にプルアップ。テストパッドを付ける（GND に落とすとリセット） |
| SWCLK（24）/ SWDIO（25） | テストパッドだけ（CM0 にはつながない） |

- **普段のファーム更新：** CM0 から UART のコマンドで「UF2 の書き込みモードで再起動」を送れるので、BOOTSEL スイッチは、初回の書き込みとファームが壊れたときの復旧用。

## 5.1 CM0 の USB ブート要求

| 信号 | 接続 |
|---|---|
| `BOOT_EN`（GPIO23） | cm0 シートの Q202（2N7002）のゲートへ。High で CM0 の nRPI_BOOT を Low に引く |

- 要求はキーの組み合わせで出す（専用のスイッチ SW102 とプルアップ R104 は廃止。GPIO20 はキーの RGB に回した）。
- RP2040 は要求を受けたら、`BOOT_EN` を High にしてから GLOBAL_EN を解除する（電流宣言が Default でも、CM0 だけ ON にする）。

## 5.2 キーの RGB

| 信号 | 接続 |
|---|---|
| `RGB_DATA`（GPIO14） | keymatrix シートのバッファ（SN74AHCT1G125）へ。PIO で出す |
| `RGB_EN`（GPIO20） | keymatrix シートの 2N7002 のゲートへ。High で `+5V_LED` が ON（プルダウンは keymatrix シート側） |

- LED の電源を切っているときは、`RGB_DATA` を Low にしておく。

## 6. USB（Port A）

| RP2040 | 接続 |
|---|---|
| USB_DP（47） | 27 Ω を介して `USB_A_D+`（power シートから） |
| USB_DM（46） | 27 Ω を介して `USB_A_D-`（power シートから） |

- **27 Ω の位置：** RP2040 の近くに置く。
- **PC がつながっているかの判定：** `CC1_A` / `CC2_A` の電圧で判定し、つながっていないときは USB を有効にしない（自分で給電しているデバイスなので、相手がいないときに D+ をプルアップしてはいけないため）。

## 7. GPIO

| GPIO | ピン | 信号 | 接続先 | 備考 |
|---|---|---|---|---|
| 0〜6 | 2〜8 | `ROW0`〜`ROW6` | keymatrix | |
| 7〜12 | 9, 11〜15 | `COL0`〜`COL5` | keymatrix | 内部のプルアップを使う |
| 13 | 16 | `KB_INT` | cm0 | オープンドレインで Low に引くだけ（プルアップは cm0 シート側）。テストパッド TP108 |
| 14 | 17 | `RGB_DATA` | keymatrix | キーの RGB のデータ（PIO） |
| 15 | 18 | `CM0_PWROFF` | cm0 | ゲートのプルアップは cm0 シート側 |
| 16 | 27 | `RP_TXD` | cm0 | UART0 TX。cm0 シートのバッファへ |
| 17 | 28 | `CM0_TXD` | cm0 | UART0 RX。**プルなし** |
| 18 | 29 | `LCD_EN` | power | プルダウンは power シート側 |
| 19 | 30 | `PWR_ST` | power | プルアップは power シート側 |
| 20 | 31 | `RGB_EN` | keymatrix | High でキーの RGB の電源が ON（プルダウンは keymatrix シート側） |
| 21 | 32 | `CM0_RUN_PG` | cm0 | **プルなし** |
| 22 | 34 | `CM0_HALT` | cm0 | **プルなし** |
| 23 | 35 | `BOOT_EN` | cm0 | Q202 のゲートへ（プルダウンは cm0 シート側） |
| 24〜25 | 36〜37 | `KB_SDA` / `KB_SCL` | cm0 | I2C0（ターゲット）。**プルなし**（プルアップは cm0 シート側）。テストパッド TP106 / TP107 |
| 26〜29 | 38〜41 | `CC1_A` / `CC2_A` / `CC1_B` / `CC2_B` | power | 各 1 kΩ の直列抵抗を介して ADC へ |

- **CC の直列抵抗（1 kΩ）：** 過電圧保護でその入力が遮断され、RP2040 の電源が切れているときでも、相手の Rp から ADC のピンに電流が流れ込みすぎないようにするため。
- **配置で入れ替える可能性：** RP2040 の外周のピンの並びを見て、キーマトリクスの配線が交差しないように、ROW と COL の割り当ては基板の配置のときに調整する。

## 8. テストパッド

`+3V3`、GND、RUN、SWCLK、SWDIO、`KB_SDA` / `KB_SCL`（GPIO24 / 25。TP106 / TP107）、`KB_INT`（GPIO13。TP108）。

## 9. シート外とつなぐグローバルラベル

| ラベル | 向き |
|---|---|
| `USB_A_D+` / `USB_A_D-` | 双方向（↔ power） |
| `CC1_A` / `CC2_A` / `CC1_B` / `CC2_B` | 入力（← power） |
| `PWR_ST` | 入力（← power） |
| `LCD_EN` | 出力（→ power） |
| `CM0_PWROFF` / `BOOT_EN` / `RP_TXD` / `KB_INT` | 出力（→ cm0） |
| `KB_SDA` / `KB_SCL` | 双方向（↔ cm0） |
| `CM0_TXD` / `CM0_RUN_PG` / `CM0_HALT` | 入力（← cm0） |
| `ROW0`〜`ROW6`、`RGB_DATA`、`RGB_EN` | 出力（→ keymatrix） |
| `COL0`〜`COL5` | 入力（← keymatrix） |

## 回路図を描きながら決めること
- [ ] XC6206P332MR-G（C5446）の絶対最大定格の確認（入力 6.2 V 程度に耐えるか）
- [ ] 22ピン FPC コネクタの選定（両面接点タイプを推奨）
- [ ] タクトスイッチの選定（BOOTSEL と CM0 の USB ブート要求。同じ部品にする）
- [ ] 22 ピン DSI のピン配置を、Raspberry Pi 5 の資料と実物の FFC で照合する
- [ ] MAX98357A の SD_MODE の抵抗（R402）の値を、データシートの内部プルダウンの値から決める
- [ ] RP2040 の水晶（C9002、負荷容量 20 pF・ESR 80 Ω）の負荷コンデンサと XOUT の直列抵抗を、ハードウェア設計資料で確かめる
- [ ] 抵抗・コンデンサの大きさ（0402 か 0603）とフットプリントの割り当て
- [ ] TPS2121 出力側のコンデンサの部品選定
- [ ] RTC の水晶の負荷容量の確認（PCF8563 のデータシートの特性は負荷容量 8 pF の水晶が前提。選んだ水晶は 12.5 pF なので、時計が少し進む可能性がある。OSCI に調整用のコンデンサが要るか、試作で測って判断する）
- [ ] 電池ホルダーのパッド寸法の確認

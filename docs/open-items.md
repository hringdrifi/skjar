# 残件

2026-10-30 時点。決まったことは [design-decisions.md](design-decisions.md) にある。

## 基板の配置の前に決めること
- [ ] キー配列とキーの数（キーマトリクスの形が決まる）
- [ ] キースイッチの種類、ホットスワップにするか
- [ ] タイピングアングルの角度と、ケースの外形
- [ ] 2層・1枚が成立するかの検討（駄目なら2枚構成）
- [ ] FFC と電源ケーブルの穴の位置（2機種の付属ケーブルの長さで届く位置）
- [ ] ディスプレイの取り付け（2機種で、取り付け穴の位置が約 1 mm、厚みが約 3 mm 違う）
- [ ] 電池ホルダーの向き（MY-2032-08 か -08-R か）
- [ ] アンテナの貼り付け位置（CM0 から 60 mm 以内。TOUCH-A のアルミ背面を避ける）
- [ ] 熱の逃がし方（裏面の CM0 からケースの底板へ逃がす案）
- [ ] ケースの材質

## 回路図を描きながら決めること
- [ ] 過電圧保護（TPS2121 の OV1 / OV2）を付けるか
- [ ] 22ピン FPC コネクタの選定（両面接点タイプを推奨）
- [ ] nRPI_BOOT 用のタクトスイッチの選定と、RP2040 から読むときの分離方法
- [ ] 各部の抵抗値（PR1 / CP2 の分圧、ILM、SS など）
- [ ] TPS2121 出力側のコンデンサの部品選定
- [ ] USB の保護素子（ESD・サージ対策の TVS）の選定
- [ ] RP2040 周辺の部品（QSPI フラッシュ、12 MHz 水晶、3.3V レギュレータ、BOOTSEL）
- [ ] RV-8263-C7 の I²C ピンが、VDD（約 3.0 V）を超える電圧を受け付けるかの確認
- [ ] 電池ホルダーのパッド寸法の確認

## 実物で確認すること
- [ ] LCD の最大電流と突入電流（バックライト 0〜100%）
- [ ] 4.5〜4.7 V で LCD と CM0 が正常に動くか
- [ ] 最大負荷のときの電圧（テストパッドで測る）
- [ ] CM0 のシャットダウン時間
- [ ] CM0 で DSI が 60 Hz で出るか
- [ ] CM0 の外形寸法の照合
- [ ] 1.5 A のときのバックライト上限値
- [ ] TOUCH-A の取り付け穴の位置
- [ ] ED-ANT-C の入手（EDATEC への問い合わせ）

## ソフトウェア
- [ ] UI フレームワーク（LVGL か SDL2 か）
- [ ] CM0 と RP2040 の間の UART でやり取りするデータの形式
- [ ] CM0 のウォッチドッグ（「動作中」の信号が途絶えたときの扱い）
- [ ] キーボードのファームウェア（QMK など）

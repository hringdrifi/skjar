# case

ケースの設計データを置く。一体型（仮の形。ねじの位置などは基板に合わせて詰める）。基板は、後ろの縁のコネクタを壁の穴に差し込みながら斜めに入れて寝かせる。そのため、キーの部分の上面を低くしてある。決めたことは [docs/design-decisions.md](../../docs/design-decisions.md) の 7 章にある。

| ファイル | 内容 |
|---|---|
| `make_case.py` | ケースを作るスクリプト。寸法はすべて先頭の定数にある |
| `skjar-case-onepiece.step` | `make_case.py` が作るケース。ディスプレイのまわりの上面はガラスと同じ高さで、キーの部分は 4.0 mm 低い（15° の斜面でつなぐ）。底はタイピングアングル 3.5° のくさび形。ディスプレイと基板を留める柱、後ろの壁のコネクタの穴、BOOTSEL を押す穴がある |
| `skjar-case.step` | ユーザーが Fusion で作った一体型のモデル（2026-11-03）。`make_case.py` はこれと同じ形を作る（体積の差は 1 mm³ 以下） |

## 作り直し方

外形・基板の大きさ・ねじやコネクタの位置は、基板ファイル（`hardware/pcb/skjar.kicad_pcb`）から読む。基板を保存してから流す。

- **外形（上から見た形）：** 基板の User.1 層（名前は「Case」）に描いた線・円弧・四角・円。閉じた輪郭にする（0.01 mm 未満のすき間はつなぐ）。描いてなければ、スクリプトの定数で決まる角丸の四角になる。
- **基板の大きさ：** Edge.Cuts の外形。基板とキーの入る穴の大きさになる。
- **基板を留めるねじ：** リファレンスが `H<番号>` のフットプリント（取り付け穴）の位置に柱を立てる。1 つもなければ、スクリプトにある仮の 12 か所を使う。
- **後ろの壁の穴と底の穴：** USB-C（J1、J2）、イヤホン（J402）、microSD（J201）、BOOTSEL（SW101）の位置に合わせる。

```bash
"C:/Program Files/FreeCAD 1.1/bin/freecadcmd.exe" hardware/case/make_case.py
```

## 座標

KiCad が書き出す基板の STEP（`kicad-cli pcb export step`）と同じ座標にしてある。重ねて読み込めば、そのまま基板と位置が合う。

- X は KiCad の x、Y は KiCad の y の符号を逆にしたもの、Z は基板の裏面が 0。
- KiCad の 3D 表示には、基板の (0, 0) に置いたフットプリント `Skjar:SKJAR_Case`（CASE1）で出している。`skjar-case-onepiece.step` をそのまま読むので、作り直せば表示も変わる（KiCad を開いたままなら、3D ビューアで再読み込みする）。
- 基板が水平の向きで描いてある。机に置いた向きで見るときは、X 軸のまわりに −3.5° 回す（手前が下がる）。

## 主な寸法

- ディスプレイの向き：DISP1 の回転を読んで、スタッドの柱と裏蓋の逃げを回す（今は 180°）。
- 外形 243.5 × 153.6 mm（User.1 の外形。角の半径は奥 3.5 mm、手前 9 mm）。厚さは手前 15.4 mm、奥 24.8 mm。
- ガラスのまわりの縁は 1.4 mm。左右と手前の壁は 7.0 mm。後ろの壁は約 2.0〜2.4 mm（ディスプレイの裏蓋の後ろが 2.0 mm）、左の壁はディスプレイの裏蓋の横で約 3.1 mm（ディスプレイを 180° 回したので、裏蓋の出っ張りが左に来る）。
- 内側のすき間：基板のまわり 0.45 mm、ディスプレイの裏蓋のまわり 0.5 mm。
- キーの部分：ガラスの穴の手前の縁から 1.2 mm 先で下り始め、15° の斜面（両端は半径 9 mm の丸み）で 4.0 mm 下がる。
- ガラスの穴は、ガラスより四方に 0.22 mm 大きい。上の外側の縁は 1 mm、底の外側の縁は 0.3 mm 丸める。
- ディスプレイ：スタッド 8 本を基板の穴に通し、ケースの柱（Ø6）に下から M2.5 で留める。
- 基板：ケースの柱（Ø5、M2 のインサート）に上から留める。12 か所。

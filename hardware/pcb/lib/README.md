# lib

このプロジェクト専用のシンボル（`skjar.kicad_sym`）、フットプリント（`skjar.pretty/`）、3D モデル（`3dmodels/`）。プロジェクトのライブラリ名はどちらも `Skjar`。

3D モデルのファイルはリポジトリに含めない。入手元は [3dmodels/README.md](3dmodels/README.md) に記録する。

## 出典の記録

外部のライブラリから取り込んだ部品は、出典をここに記録する。特に LCSC / EasyEDA（JLCEDA）の公式ライブラリから取り込んだものは、配布するときに出典の明記が求められている（[EasyEDA](https://easyeda.com) / [嘉立創EDA](https://lceda.cn/)）。

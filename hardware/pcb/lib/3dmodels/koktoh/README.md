## 作者の注意事項の要点

- **禁止：** このモデルをもとに立体物を作って販売すること（縮尺を変えたものも含む）、3D モデルそのものを販売すること。
- **許可：** KiCad のフットプリントに 3D モデルとして紐づけること（販売目的の基板でもよい）、販売するキーボードの宣伝用レンダリングに使うこと、個人の範囲で立体化すること。

詳しくは上の注意事項の記事を参照。

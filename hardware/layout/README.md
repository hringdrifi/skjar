| ファイル | 内容 |
|---|---|
| `skjar_kle.json` | キー配列（KLE 形式。Smidr で作成） |

## 概要

- **キーの数：** 42（幅はすべての行で 12u）
- **最上段の 12u × 3.5u の空欄：** ディスプレイの位置を示す目印。キーではない
- **最下段：** スペースは 2.75u と 2.25u に分割（どちらもスタビライザーが要る）

```text
┌──────────────────────────────────────────────────────┐
│                  ディスプレイ（12u × 3.5u）             │
├────┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬────────┤
│Esc │ Q │ W │ E │ R │ T │ Y │ U │ I │ O │ P │ Bksp   │
├────┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴────────┤
│Tab  │ A │ S │ D │ F │ G │ H │ J │ K │ L │  Enter    │
├─────┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬────────┤
│LShift │ Z │ X │ C │ V │ B │ N │ M │ , │ . │ / (SFT)│
├─────┬─┴──┬┴───┴┬──┴───┴───┼───┴───┴───┼───┼───┬────┤
│LCtrl│LGui│LAlt │ Space L1 │ Space L2  │RAlt│RGui│RCtrl│
└─────┴────┴─────┴──────────┴───────────┴────┴────┴─────┘
```

- **右下の `/`：** 押すと `/`、長押しで Shift（SFT）。
- **スペース 2 つ：** 長押しでレイヤー 1 / レイヤー 2 に切り替える（タップでスペース）。

## キーマトリクス（7 行 × 6 列、COL2ROW）

左右の半分をそれぞれ別の行にし、列は左右とも外側から COL0 → COL5（中央で折り返す）。2・3 段目の右半分は 5 キーなので、空いた C0 に最下段の RGui（ROW5）と RCtrl（ROW3）を入れる。ダイオードは列 → スイッチ → ダイオード → 行の向き（カソードが行側）。

| 段 | 左半分 | 右半分 |
|---|---|---|
| 1 | Esc R0C0、Q R0C1、W R0C2、E R0C3、R R0C4、T R0C5 | Y R1C5、U R1C4、I R1C3、O R1C2、P R1C1、Bksp R1C0 |
| 2 | Tab R2C0、A R2C1、S R2C2、D R2C3、F R2C4、G R2C5 | H R3C5、J R3C4、K R3C3、L R3C2、Enter R3C1 |
| 3 | LShift R4C0、Z R4C1、X R4C2、C R4C3、V R4C4、B R4C5 | N R5C5、M R5C4、, R5C3、. R5C2、/ R5C1 |
| 4 | LCtrl R6C0、LGui R6C1、LAlt R6C2、Space(2.75u) R6C4、Space(2.25u) R6C5 | RAlt R6C3、RGui R5C0、RCtrl R3C0 |

以前の自作キーボード（blad）で実績のある割り当て。

## 形式

KLE と同じ形式。2 行目の `"y": 2.5` で、キーの行をディスプレイ（高さ 3.5u）の真下から始めている。
